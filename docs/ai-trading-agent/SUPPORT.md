# AI Trading Agent Support

Report package problems or ask usage questions through the AI-Skills repository's issues page:
https://github.com/ajitsutar/AI-Skills/issues

Include the skill version, host name, requested workflow, expected result and actual result. A small fictional or sanitized example and the exact non-sensitive error text help reproduce a problem. Identify missing tools or dependencies without sharing account access.

GitHub issues are public. Never post passwords, API keys, authorization headers, cookies, SEC contact configuration, account identifiers, private financial documents, real portfolio exports or trading records. Remove sensitive content from screenshots and logs. Use fictional amounts and identifiers when possible. Do not post a secret to ask whether it is safe.

For account access, authentication, billing, service outages or the status of a real order, use the relevant host, data provider or broker's own support channel. This repository cannot establish an order's outcome from a local report.

The repository can track package defects, documentation questions and feature requests. No response time or service-level commitment is stated.
