## Maintenance and future imports

When adding externally sourced code or substantial prose, record the original
author/project, exact source URL or revision, applicable license, modifications
and required notice in the affected skill before distributing it. Retain existing
credits. If no source has been established, say so; a failed web search or an
AI-generated patch is not proof of independent authorship.

Keep each skill's LICENSE, PROVENANCE.md and THIRD-PARTY-NOTICES.md in standalone
copies. Do not substitute a software architecture's license for a checkpoint's
terms, and do not bundle dependencies or assets under the repository's MIT label.
The October 12 maintenance changes add these records, method citations and
explicit model-use boundaries without manufacturing permission from unknown owners.
