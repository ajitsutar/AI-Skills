# Source provenance and licensing

Repository-authored code and documentation are offered under the [MIT license](LICENSE).
Each standalone skill retains its own license, source provenance and
[third-party notices](THIRD-PARTY-NOTICES.md). External dependencies, model weights,
publications, market data and user media retain their applicable terms.

When incorporating externally sourced material, record its original author/project,
source URL or revision, applicable license, changes and required notices in the
affected skill. Preserve existing credits. AI generation, a repository author label
or an unsuccessful source search does not independently establish ownership.

Keep historical source-audit reports and comparison results in the maintainer's
local archive. Public provenance files describe current origins, dependencies and
license boundaries. Keep those notices with every standalone distribution.
