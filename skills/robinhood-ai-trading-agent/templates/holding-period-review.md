# Holding-period run record

Use with [screen-review.md](screen-review.md); this does not authorize an order.

- Skill/code/data versions, run as-of time and market timezone:
- User objective and risk/cash-availability needs:
- Proposed entry/time/price, latest entry and expiry:
- Duration and units; anchor date; fixed end or rolling from actual fill:
- Strategy route: intraday / swing / long_term; forced exit versus thesis review horizon:
- Raw deadline, resolved exchange session, close buffer and hard exit:
- Calendar confirmed-through date; provisional future sessions and refresh triggers:
- Early risk exits allowed or strict hold; settlement/withdrawal plan if relevant:
- Event policy: entry_only or entry_and_hold; excluded kinds; sessions before/after;
  coverage/freshness, uncertain-date policy and post-event release/review condition:
- Full-hold event coverage or rolling review; next review and recurring-event risks:
- Method chosen before selection; universe/peer/selection rules and actual coverage:

## Per candidate

- Latest public financial period/publication time; period actually reviewed;
  latest-release check time and issuer/filing evidence:
- Primary sources attempted, normalized bridge, unresolved material questions:
- Thesis timing: before-exit mechanism, expectations already priced in, falsifier:
- Events: release versus call, confirmed/estimated window/timezone, source;
  entry blackout, holding exposure and explicit decision about that exposure:
- Terminal valuation: same-exit downside/base/upside, assumptions and evidence;
  distributions, round-trip costs, net returns and same-period cash benchmark:
- Downside/liquidity: overnight gap, correlated shock, forced-sale and halt risk:
- Portfolio fit: issuer/theme/sector aggregation, event clustering, affordability:
- Exit plan: trigger/expiry, early-exit rule, hard deadline, supervision/handoff:
- GARCH computation/audit/validation/sizing status or explicit skip reason:
- Fundamental, horizon and event statuses separately; final disposition:
- What changes at a later entry or different price? Required rerun/next review:

## Final report

- Eligible comparison versus Watch priorities; no quota and no implied execution:
- Compared alternatives/no action; material assumptions that reverse ranking:
- Missing source/model work and concrete attempts made; remaining limitations:
- If comparing agents: common cutoff, skill version, universe, model/settings,
  tools/data access, history/mandate, method and primary corrections:

Keep probability of profit unavailable unless supported by a separately validated
and calibrated model. Scenario averages and analyst targets are not probabilities.
