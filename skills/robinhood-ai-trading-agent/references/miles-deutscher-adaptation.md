# Context for the Miles Deutscher acknowledgment

The predecessor credited Miles Deutscher's approach to persistent investor context.
A related [primary guide](https://milesdeutscher.com/assets/how-i-made-claude-do-the-work-of-5-people-full-guide-cbb1fbb5)
describes using Claude for recurring work and financial research. The exact X post
named in the original upload has not been independently identified.

In this package, descriptive investor preferences belong in the
[investment brief](../templates/investor-philosophy.md). Current positions must be
reconciled with the broker, and each research conclusion needs dated evidence.
A prior conversation or an influencer's example cannot establish current holdings,
grant execution authority or validate expected returns.

This note replaces the inherited adaptation text in version 3.2. It preserves
the historical credit without reproducing the source's workflow text. The skill's
operational rules are maintained in SKILL.md and its relevant references.
See [all acknowledgments](../SOURCES.md) and [provenance](../PROVENANCE.md).
